##📝 Project Overview

This project focuses on the design and implementation of a key tag detector circuit that activates an audible alert when two consecutive hand claps are detected within a three-second interval. The system provides a simple and effective solution for locating misplaced keys using sound-based triggering.

The circuit is fully analog, powered by a battery, and designed under strict constraints that prohibit the use of logic gate ICs, relying only on 555 Timer ICs for timing and control.

##🎯 Objectives

-Detect two consecutive hand claps within a limited time window

-Trigger a distinct audible tone for key tag identification

-Design a compact, low-cost, and battery-powered circuit

-Optimize component usage without unnecessary elements

##⚙️ Working Principle

The circuit operates in four main stages:

Sound Detection: A microphone senses acoustic signals from hand claps

Signal Conditioning: Noise filtering ensures only sharp clap sounds are processed

Timing Control: Two 555 Timer ICs configured as monostable multivibrators generate timing pulses

Alert Activation: If two claps occur within three seconds, the buzzer is triggered to produce an audible alert

##🖥️ Design & Implementation Process

-Simulation: Circuit designed and verified using Proteus

-Breadboard Testing: Real-time testing and validation

-PCB Design: Layout created using EasyEDA

-Fabrication: Copper board etching, drilling, soldering, and assembly
